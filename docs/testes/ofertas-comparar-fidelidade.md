# Roteiro de teste: fidelidade de Ofertas, Comparar e Favoritos

Conferir cada tela do app com a prancha do protótipo. Desktop 1440 px, tablet 800 px, celular 390 px (sem rolagem horizontal; alvos de toque de 44 px).

| URL do app                                             | Prancha do protótipo               | O que conferir                                                                                                                                                                                                                                    |
| ------------------------------------------------------ | ---------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `/ofertas`                                             | `Ofertas`                          | Cabeçalho com "Perto de"; 4 cupons (borda tracejada, código mascarado até pegar); "Menores preços"; barra fixa (busca, categorias, raio, ordenação, "Aberto agora"); grade de 4; "Ver mais ofertas"; banner "Não achou o que queria em promoção?" |
| `/ofertas` (sem dados / erro / carregando / visitante) | `Ofertas` (estados)                | Telas distintas; "Pegar cupom" pede conta para visitante e retoma depois do login                                                                                                                                                                 |
| `/comparar`                                            | `CompararSelecao`                  | Voltar, 3 passos, busca ("Nova busca"), bandeja "Sua comparação" na mesma linha, ordenação, filtros, Lista/Mapa, "Relacionados", cartões com "+ Comparar" / "Na comparação" / "Outra categoria" / "Comparação cheia"                              |
| `/comparar?q=tênis`                                    | `CompararSelecao` (com resultados) | Selecionar 3, X nos espaços, "Comparar opções →" só com 2 ou mais                                                                                                                                                                                 |
| `/comparar/quadro`                                     | `CompararE1`                       | "Voltar à pesquisa", "Salvar comparação", "Mostrar só o que é diferente", prioridades (até 3, numeradas), 3 colunas com "Salvo da {loja}", "Adicionar opção", aviso                                                                               |
| `/favoritos`                                           | `Favoritos`                        | 4 atalhos; abas com contadores; filtros e ordenação; cartão com "+ Comparar" à esquerda e coração à direita, "o que mudou", "Salvo há…", "Em N lista", contorno âmbar na comparação                                                               |
| `/favoritos?aba=lojas`, `listas`, `alertas`            | `Favoritos` (abas)                 | Conteúdo de cada aba, criar/renomear/apagar lista, ativar/editar/cancelar alerta                                                                                                                                                                  |

Limitações conhecidas: Mapa depende do serviço de mapas; nada foi validado com a API real; o campo "Buscar nos favoritos" não existe no protótipo (mantido).
